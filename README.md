## 💼 Experience

### 🏢 Frontend Developer — Aziro Technologies, Chennai
**December 2021 – Present · 4+ Years**

<details>
<summary><b>🌍 Global Scale</b> — Multilingual Event Platform (12+ Languages)</summary>

- Architected locale routing with **Next.js App Router** dynamic segments + `hreflang` tags — 12+ language variants from a **single codebase**
- Modeled **Strapi CMS** for per-locale field overrides — regional teams update copy with **zero deployments**
- Pre-generated all locale/page combos at build time (**SSG**) + ISR fallback for low-traffic variants — **origin load near zero** during campaign spikes
- Set up **GitHub Actions** to trigger ISR revalidation on CMS publish events — eliminated manual rebuild cycles across 12+ regions

</details>

<details>
<summary><b>⚡ Performance Engineering</b> — Heartfulness.org Migration</summary>

- Planned and executed **zero-downtime** React SPA → Next.js App Router migration with incremental route wrapping + **feature flags per page group**
- Diagnosed LCP bottlenecks using **Chrome DevTools + Lighthouse CI** — fixed via `next/image` priority loading, critical CSS extraction, render-blocking script removal
- Replaced bespoke component library with **ShadCN UI** — wrote migration guide, set up shared **Tailwind design token config** for visual consistency across teams
- Result: **57% faster load times** (7s → <3s) and **70% session duration increase**

</details>

<details>
<summary><b>🎓 Product Engineering</b> — Multi-Tenant Yoga LMS</summary>

- Designed **subdomain-based org isolation** — each org resolves to its own Strapi content space (courses, quizzes, users) with zero shared-data leakage
- Built quiz engine as a **finite state machine** (`idle → in-progress → submitted → graded`) using Redux Toolkit; supports auto-save + resume on refresh
- Handled **Razorpay webhook verification** server-side with signature validation before access provisioning — no course access on failed or tampered payments
- **100% automated** grading & certificate generation — zero manual intervention at 700K+ attendee scale

</details>
